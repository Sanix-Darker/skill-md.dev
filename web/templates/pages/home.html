Bring your own skill source.

Protocol

  • Use the exact source you trust. No registry-first workflow, no required catalog search, no noisy discovery surface.
  • Normalize before you merge. Convert each source into a clean skill first, then merge only the files you actually want to combine.
  • Keep terminal access explicit. The terminal route exists to open skillf in a shell session without turning the web UI into a pseudo-dashboard.

Workflow

One source in. One clean skill out.

The product stays small on purpose: import, normalize, merge, then move on.

01

Import the source

Paste a link, drop raw content, or upload a local file without committing to any external registry or browse flow.

02

Convert to a skill

03

Merge only when needed

Upload multiple skill files, choose the merge policy, and produce one combined artifact when the workflow calls for it.
